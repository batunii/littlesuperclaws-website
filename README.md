# LittleSuperClaws.ie — Website

A living, AI-agent-themed marketing site for **Little Super Claws** — the world's
first fully agentic comedy crew, hidden across Dublin. Built from the CTO Master
Brief and the concept/character art in this pack.

It's a **zero-build, fully static site** (HTML + CSS + vanilla JS) so it opens
instantly anywhere and is trivial to host. The design and copy map directly onto
the Next.js build described in the brief, so it can later be ported component-for-
component.

## Run it

**Serve the folder** (the live WebGL city is an ES module, so `file://` won't
load it — a local server is required):

```powershell
# from this folder
python -m http.server 8000
# then visit http://localhost:8000
```

> Needs internet on first load: Google Fonts + Three.js (pinned to
> `three@0.160.0` via an import map). No build step, no `npm install`.

## Live WebGL — the splatted Dublin (`#explore`)

A real-time **Three.js point-cloud city** standing in for the Gaussian-splat
Dublin the brief describes. ~16k points form a street of buildings down a central
"Liffey" gap, with lit windows, drifting firefly dust and **glowing 3D portal
rings** to Temple Bar, the Ha'penny Bridge and the Spire.

- **Drag to look around**; gentle auto-dolly + mouse parallax otherwise.
- **Recolours with the time-of-day modes** (day / evening / night / rain) — the
  same toggle that themes the whole site drives the scene.
- **Portal labels** are HTML projected onto the 3D rings each frame; click one to
  fire the scene generator for that location.
- Pauses its render loop when off-screen, caps pixel ratio, honours
  `prefers-reduced-motion`, and **falls back to a static image** if WebGL is
  unavailable.

## The "living site" touches

- **Time-of-day theming** — day / evening / night / **rain** modes. Auto-selects
  by local time; toggle in the nav, or deep-link with `?mode=night`.
- **Search → scene generation** — type any Dublin location (or use a chip) and the
  agents "build" a scene with a live step-by-step log and portal reveal.
- **Deep-linkable scenes** — `?scene=Temple%20Bar` lands straight on a generated
  scene (handy for shared links).
- **Live agent badge + request feed** — rotating agent status and an updating feed
  of "trending locations", echoing the brief's runtime-agent fleet.
- Animated ticker, marquee, scroll reveals, glassy sticky nav, full responsive
  layout, and `prefers-reduced-motion` support.

## World Labs (Marble) integration — real generated worlds

The scene generator and the `#explore` section are now backed by the **real
World Labs Marble API** (`api.worldlabs.ai/marble/v1`), rendered with
**Spark** (World Labs' Gaussian-splat renderer for Three.js):

- `config.js` — API key + model (`marble-1.1`). ⚠️ Client-side key: fine for a
  local demo, move behind a proxy for production.
- `worldlabs.js` — API client: resolve location → pregenerated manifest →
  localStorage cache → live `worlds:generate` (~5 min, then cached).
- `worlds-manifest.js` — generated by `tools/pregen.py`; world IDs for the
  pregenerated Dublin locations (chips + portals + the explore world).
  Signed asset URLs expire, so the site re-fetches world details by ID.
- `splatviewer.js` — Spark `SplatMesh` viewer (`.spz`, 500k res; 100k on
  mobile) used by the scene modal and `#explore`. Drops the five crew GLBs
  onto the world's real floor (raycast against Marble's collider mesh),
  with idle bob/sway. Drag to look, scroll/WASD to walk.
- `splatcity.js` — the original procedural point-cloud city, now the
  automatic fallback when no explore world / WebGL2 is available.
- `tools/pregen.py` — pre-generates the fixed Dublin worlds in waves
  (the API allows ~3 concurrent generations) and writes the manifest.
  Safe to re-run; it skips completed worlds.

Pipeline (per the architecture screenshot): character GLBs + **World Labs
Marble environment** (`.spz` Gaussian splats + collider mesh) → **Spark ·
Three.js · WebGL2** in the browser.
